Python & Laravel training in Dharan

I teach programming at CodeIT in Dharan, covering Python, Laravel and related web technologies. I’m also a working developer who leads the software department at CodeIT Appsware, so what you learn comes from real projects, not just textbooks.

What I teach

  • Python: fundamentals, problem solving, working with data and building small applications.
  • Laravel and PHP: building real web applications, from routing and databases to authentication and APIs.
  • Web development basics: HTML, CSS, JavaScript and modern front-end tools such as Vue and Tailwind.
  • Career skills: Git, working in teams, reading documentation and shipping projects.

How classes work

Lessons are hands-on and project-based. Students build working applications, get feedback on their code, and finish with work they can show employers.

Who it’s for

Students, graduates and career-changers in Dharan and eastern Nepal who want practical programming skills.

Batches and enrolment

For current batches, schedules and fees, please contact CodeIT directly or message me and I’ll point you to the right place.

Common questions

Do I need prior experience?

No. Beginner-friendly tracks start from the basics, and there are paths for people who already know some programming.

Which should I learn first, Python or Laravel?

Python is a gentle first language and useful in many fields. Laravel is a great choice if your goal is building websites and web apps quickly. I’m happy to advise based on your goals.

Can I learn from a project I’m building?

Yes. Bring your project idea and we can shape the learning path around it.
